# 架构

Sink 在 Cloudflare Workers 或 Pages 上运行仪表盘、API 和短链接跳转。

## 有人打开短链接时发生什么

1. 访问者打开你域名下的短链接
2. Sink 查找链接并执行重定向（或根据已保存的设置显示密码/警告页；DoH 安全检测发生在创建/编辑短链时，而非跳转时实时检查）
3. 你在仪表盘或通过 API 管理链接（都需要登录）
4. 若启用了访问分析，访问会出现在报表和日志里

## Sink 用到的 Cloudflare 服务

| 绑定名称    | 产品             | 是否必需 | 说明                           |
| ----------- | ---------------- | -------- | ------------------------------ |
| `DB`        | D1               | 必需     | 保存链接的数据库               |
| `ANALYTICS` | Analytics Engine | 推荐     | 记录访问事件，供图表和日志使用 |
| `R2`        | R2               | 可选     | 对象存储，用于备份和社交图片   |
| `AI`        | Workers AI       | 可选     | 建议短链码和标题               |

**D1** 保存所有链接。跳转直接读取 D1，所以编辑或删除会在下一次访问时立即生效。

R2 和 AI 是可选增强。请从[快速开始](./getting-started)开始。
